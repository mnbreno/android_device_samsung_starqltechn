# Changelog

## 3.7.0-android10

- Device tree for TWRP on **Android 10** firmware (SM-G9600 / starqltechn).
- Based on TeamWin android-9.0 tree; compatible with twrp-9.0 manifest build.
- Local build script `scripts/build-twrp.sh` to build and package Odin-ready recovery .tar.
- README: build options, release instructions, vbmeta and flashing notes for Android 10.
